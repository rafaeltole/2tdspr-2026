# Java Advanced

Material de apoio utilizado durante as aulas da disciplina **Java Advanced**.

Ao longo da disciplina, acompanharemos a evolução de uma aplicação Java, começando pela compreensão do domínio e avançando para o desenvolvimento de APIs com Spring Boot.

## Organização do conteúdo

O material está organizado por semanas e aulas:

- `01-semana/01-aula`: domínio e primeira versão da aplicação;
- `01-semana/02-aula`: continuação da aplicação;
- `02-semana`: conteúdos da segunda semana.

## Conteúdo das aulas

### Semana 1

- [Aula 1 — Domínio e modelo de domínio](01-semana/01-aula/)
- [Aula 2 — Aplicação SpringWeb](01-semana/02-aula/)

## Tecnologias utilizadas

- Java
- Maven
- Spring Boot
- IntelliJ IDEA
- Git e GitHub

## Como utilizar este repositório

1. Localize a semana e a aula desejadas.
2. Leia o `README.md` da aula.
3. Acesse o diretório `aplicacao-exemplo`.
4. Siga as instruções para executar o projeto.
5. Realize os exercícios propostos.
