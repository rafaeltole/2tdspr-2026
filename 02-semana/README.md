# Semana 2 — Conhecendo Spring Web e Spring Data JPA

Nesta segunda semana, desenvolveremos uma API REST para o gerenciamento de alunos. Durante as aulas, utilizaremos o Spring Web e o Spring Data JPA, aplicaremos a arquitetura em camadas e implementaremos o tratamento de exceções.

## Objetivos da semana

* Conhecer o Spring Web e suas principais anotações;
* Compreender a organização de uma aplicação em camadas;
* Conhecer o Spring Data JPA;
* Desenvolver um CRUD de alunos;
* Implementar o tratamento de exceções.
